# Сайт Snarro

Статическая страница: `index.html` и картинки в `assets/`. Сборки нет.
Публикуется через GitHub Pages из ветки `main`, папка `/ (root)`:
https://oasan.github.io/snarro-site/

Репозиторий публичный: ничего закрытого сюда не класть.

## Скриншоты

Картинки окон сняты с настоящего приложения. Инструменты съёмки — в
`../assets/macos/site-shots/` (там же порядок действий): они содержат код
приложения и в публичный репозиторий не входят.

## Проверка

`node tools/preview.mjs <папка> 1440x900 light 0 '#tools'` — скриншоты страницы
в нужных местах прокрутки через Chrome DevTools, плюс проверка горизонтальной
прокрутки. Локальный просмотр: `python3 -m http.server 8000`.
